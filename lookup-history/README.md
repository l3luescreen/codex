# Lookup History

Shows the words you looked up in the dictionary, and in which book.

The list itself is written by the reader (the lookup-history firmware) to
/Lookup History.tsv (SD card root). This plugin only displays it.

On your phone: open the reader's web page (File Transfer), go to the Files
page, and find the "Lookup History" card. You can search, filter by book,
show only words the dictionary did not find, and download the list as CSV
(opens in Google Sheets or Excel) or TSV.
